Sin drama · sin código extra · paso a paso

Si algo falla, volvé al paso base.

Esta guía corta te ayuda a destrabar lo típico: kernel reiniciado, claves faltantes o Gradio sin arrancar. La idea es simple: no correr todo de nuevo a ciegas.

Orden recomendado

  1. Instalá dependencias.
  2. Configurá OpenRouter.
  3. Ejecutá la celda de la base vectorial.
  4. Revisá el grafo.
  5. Hacé una prueba mínima.
  6. Activá Gradio al final.

Claves

  • Obligatoria: OPENROUTER_API_KEY o OPENROUTER_AGENTICRAG_API_KEY.
  • Si falta OpenRouter: podés revisar instalación, documentos, vector store y grafo, pero no generar respuestas con LLM.
  • Opcionales: TAVILY_API_KEY activa web search; LANGCHAIN_API_KEY activa trazas de LangSmith/observabilidad.

Si el kernel se reinicia

Volvé a correr primero la celda de la base vectorial.

Si vector_store no existe, la celda debería recargar Chroma desde disco o crear un respaldo local.

Gradio

La UI es opcional.

Si no aparece, revisá el flag ENABLE_GRADIO dentro de su celda.

Embed estable y trazas

Para Pages, la demo estable no usa un share=True temporal de Colab: usa un hosted app como Hugging Face Spaces. Y las trazas de LangSmith se comparten como link público o captura, no como iframe autenticado.

Recordatorio seguro:

Usá la demo sin pegar información personal. Si querés probar rápido, seguí la ruta mínima y llegá al link final de Gradio.
