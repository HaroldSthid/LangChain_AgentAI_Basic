Ir al diagnóstico
La idea central

No es solo un notebook: es una ruta guiada.

La página está pensada para que cualquier persona pueda entender qué hace cada bloque sin perderse en jerga ni en pasos sueltos.

Biblioteca primero

El sistema arranca revisando su propia base local/RAG. Esa es la fuente principal: rápida, controlada y más predecible para aprender.

Internet si hace falta

Si la respuesta todavía no está clara, el flujo puede buscar en la web para completar el contexto antes de contestar.

Decidir con LangGraph

LangGraph es el cerebro y el mapa: revisa el libro, mide si algo sirve, decide si busca afuera y arma el camino final de respuesta.

Qué cambió en el script

Un asistente de investigación, no un atajo.

La explicación se escribió para que suene cercana, clara y útil para principiantes: menos magia, más pasos entendibles.

OpenRouter reemplazó a Groq

Los modelos de Groq venían más inestables y menos confiables para la parte de evaluación. Para medir si una fuente realmente sirve, OpenRouter con Claude-3-Haiku es una base más sólida y precisa.

La UI final es Gradio

Gradio es la ventana de chat al final del recorrido. No cambia la lógica: solo te permite probarla con una interfaz simple y amigable.

Todo queda más legible

El notebook está pensado para que entiendas el flujo: qué consulta primero, qué valida después y cuándo se activa la búsqueda web.

Seguro para demo

Sin código extra, sin apuro y sin datos personales. OpenRouter es necesario para que responda el LLM; Tavily es opcional y solo suma búsqueda web.

Cómo usarlo

Clics de arriba hacia abajo. Nada más.

Ruta de ejecución

  1. Abri el notebook en Colab o GitHub.
  2. Ejecutá las celdas de arriba hacia abajo.
  3. Si falta OpenRouter, revisá instalación, base vectorial y grafo, pero la respuesta con LLM no va a correr.
  4. Si falta Tavily, seguí igual: solo se desactiva la búsqueda web opcional.
  5. Volvé a correr la celda de la base vectorial si el kernel se reinicia.
  6. Terminá en el enlace final de Gradio.

Reglas simples para no trabarte

No hace falta programar de entrada OpenRouter responde; Tavily solo suma web Primero la base RAG Después web, si conviene Demo con cuidado y sin info personal
Tip:

Pensalo como una escalera: cada botón te lleva un paso más arriba. Si algo falla, no reinicies todo; retomá desde la celda que reconstruye la base.

Trace explicado

LangSmith como observabilidad compartible, no como iframe frágil.

La idea es enseñar el trace con links sanitizados, capturas o tarjetas estáticas. El UI autenticado de LangSmith no es el camino estable para Pages.

Formato recomendado

Compartí un link público, recortado y sin datos sensibles. Si hace falta, acompañalo con una captura del trace para que sea fácil de entender.

PEGAR_LINK_PUBLICO_LANGSMITH

Qué evitar

No dependas de un iframe a una vista autenticada. Tampoco pegues prompts, respuestas o metadatos con información personal.

Regla simple:

Si no podés compartirlo en público, no lo pongas en Pages.
