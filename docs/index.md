# Ruta educativa: RAG + LangGraph

Este sitio resume el notebook principal del proyecto y sirve como punto de entrada para aprender el flujo con OpenRouter.

## Qué vas a encontrar

- Instalación y preparación del entorno.
- Clave requerida de OpenRouter y claves opcionales.
- Recuperación semántica con Chroma.
- Grafo de decisión con LangGraph.
- Extensión opcional con búsqueda web y una interfaz Gradio.

## Notebook principal

- [Abrir el notebook en GitHub](https://github.com/HaroldSthid/LangChain_AgentAI_Basic/blob/main/Script_LangGraph_para_Colab_y_Diagrama.ipynb)
- [Ejecutarlo en Google Colab](https://colab.research.google.com/github/HaroldSthid/LangChain_AgentAI_Basic/blob/main/Script_LangGraph_para_Colab_y_Diagrama.ipynb)

## Cómo seguir la ruta

1. Lee el README.
2. Ejecuta el notebook desde arriba hacia abajo.
3. Prueba primero la ruta mínima RAG.
4. Si el kernel se reinicia o falta `vector_store`, vuelve a ejecutar la celda de la base vectorial.
5. Luego habilita la parte web y la UI si tienes las claves.
